# 药理学选择题训练

一个自制、可直接在线使用的药理学刷题网页，基于《药理学各章节习题》整理。

- 共 **16 章 561 道选择题**（A 型单选 / B、C 型配对 / X 型多选）
- 每题附 **答案、题干解析，以及每个选项的讲解**
- 支持按章节 / 题型 / 进度筛选、随机顺序、即时判分、错题本、做题进度统计

## 在线使用

本仓库已按 GitHub Pages 部署，直接访问：

```
https://<你的用户名>.github.io/<仓库名>/
```

（若尚未开启，见文末「如何部署」。）

## 进度保存

进度（错题 + 已答题统计）默认保存在**浏览器本地**。

跨设备 / 备份进度：

1. 在网页里点「**导出进度**」，下载 `药理学进度_日期.json`；
2. 换设备后点「**导入进度**」，选择该文件即可恢复。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 刷题网页（核心，双击或在线打开） |
| `药理学简答题整理.docx` | 简答/问答、名词解释、填空题（含答案，未做进网页） |
| `药理学选择题勘误说明.md` | 原文档答案勘误与修正说明 |

## 说明

原习题文档的参考答案存在部分错误，已按药理学教材标准答案修正（详见勘误说明）。数据仅供复习参考。

## 如何部署到 GitHub Pages

1. 在 GitHub 新建一个仓库（如 `pharmacology-quiz`），**Public 公开**；
2. 把本目录下的全部文件上传到仓库根目录；
3. 仓库 → **Settings** → **Pages**；
4. `Source` 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，点 **Save**；
5. 等待 1 分钟左右，页面会显示访问地址 `https://<你的用户名>.github.io/<仓库名>/`。
